## Recovered implementation source

A historical C# file supplied for this release contains the NSCR-related method
and several comparison algorithms in a single benchmarking program.

The clean repository does not redistribute that draft verbatim. Instead it
records its relevant behaviour in `source-audit.md` and provides a focused
reconstruction of the NSCR component.

This keeps the public repository centred on the published research method while
avoiding the implication that the draft file is the final publication source.
